Case B: Electricity Consumption and Billing System
An electricity provider needs a program to calculate household electricity bills based on
consumption and customer categories. The system can store information such as customer
name, customer category, daily electricity usage for 7 days, total usage, and electricity bill. The
maximum of households that can be stored is 20.

Minimum requirements:
• Minimum requirements:
• The system can perform household registration and record electricity consumption for 7
days.
• The system can calculate the total electricity consumption, average daily consumption,
and estimated monthly consumption based on the recorded 7-day usage.
• The system can calculate electricity bills using progressive tariffs:
o First 100 kWh: Rp1,000/kWh.
o Next 100 kWh: Rp1,500/kWh.
o Above 200 kWh: Rp2,000/kWh.
• The system can apply discounts based on customer categories: low-income customers
receive a 20% discount, middle-income customers receive a 10% discount, and highincome customers receive no discount.
• The system can identify the day with the highest electricity consumption for each
household.
• The system can show a report containing customer information, total electricity
consumption, estimated monthly consumption, discount, and final electricity bill.
